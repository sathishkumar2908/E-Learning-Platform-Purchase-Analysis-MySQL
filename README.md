# E-Learning Platform Purchase Analysis using MySQL

## Project Overview

This project focuses on analyzing e-learning platform purchase data using MySQL. The platform offers various online courses to learners across different countries.

The project uses SQL queries to analyze learner purchasing behaviour, course popularity, category-wise revenue, and learner spending patterns.

The main objective is to transform purchase records into meaningful business insights using relational database concepts and SQL analytical queries.

## Problem Statement

An online learning platform sells various digital courses to learners across different countries. Each learner can purchase multiple courses, and each course belongs to a specific category.

The management team wants to understand:
- Learner spending patterns.
- Top-performing courses.
- Revenue generated by different course categories.
- Learners purchasing courses from multiple categories.
- Courses that have not received any purchases.

The goal is to analyze this information using MySQL and provide useful business recommendations.

## Dataset Description

The project contains three relational tables:

### 1. Learners Table
| Column | Description |
|---|---|
| learner_id | Primary Key |
| full_name | Learner's full name |
| Country | Learner's country |

### 2. Courses Table
| Column | Description |
|---|---|
| course_id | Primary Key |
| course_name | Name of the course |
| category | Course category |
| unit_price | Price of the course |

### 3. Purchases Table
| Column | Description |
|---|---|
| purchase_id | Primary Key |
| learner_id | Foreign Key |
| course_id | Foreign Key |
| Quantity | Number of courses purchased |
| purchase_date | Date of purchase |

## Data Exploration Using Joins

The following JOIN operations were performed:

- **INNER JOIN:** Combined learner, course, and purchase records to display matching purchase details.
- **LEFT JOIN:** Displayed all learners, including learners without purchases.
- **RIGHT JOIN:** Displayed all courses, including courses that had not been purchased.

## Business Analysis & Key Questions

The project answers five important business questions:

**Q1. Learner Spending Analysis**

Calculated the total spending of each learner using quantity multiplied by course unit price, along with their country.

**Q2. Top 3 Most Purchased Courses**

Identified the three most purchased courses based on total quantity sold.

**Q3. Category-wise Revenue Analysis**

Calculated total revenue and the number of unique learners for each course category.

**Q4. Multi-Category Purchasing Behaviour**

Identified learners who purchased courses from more than one category.

**Q5. Unpurchased Courses Analysis**

Identified courses that had not received any purchases.
